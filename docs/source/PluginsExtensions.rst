Plugins and Extensions
=====================================

AdOpT-NET0 can be extended with additional functionality through plugins and extensions.
Plugins are modular components that can be integrated into the core system to provide new features or enhance existing ones.
Plugins are called during the execution of the core AdOpT-NET0 and can modify its behavior.
Extensions are not called during the execution of the core AdOpT-NET0, but they provide additional tools, utilities,
or data that can be used alongside the core system.
